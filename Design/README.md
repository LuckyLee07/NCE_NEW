# 新概念英语设计索引

本轮补充听写、首次使用与空状态、带横幅的练习反馈和结果，共 3 张画板、9 个页面状态。它们延续白底、蓝色强调和小幅墨线水彩插画的方向。2026-10-11 已接入原生 iOS 工程首版，覆盖学习首页、课程目录、同课切换、五种练习、结果与单词本。

原生实现与实测截图见[首版实现记录](../Docs/design/2026-10-11-implementation.md)。

## 本轮补充

| 画板 | 从左到右的状态 | 主要用途 |
| --- | --- | --- |
| [听写流程](2026-10-11-supplement/01-dictation-flow.png) | 待输入、键盘展开、拼写错误反馈 | 明确输入框、提交按钮、键盘和广告的关系 |
| [首次使用与空状态](2026-10-11-supplement/02-first-use-empty-states.png) | 无学习记录、课程搜索无结果、暂无错词 | 为没有内容的页面提供说明和可执行的下一步 |
| [带横幅的练习反馈与结果](2026-10-11-supplement/03-practice-results-with-banner.png) | 答错反馈、有错词的结果、全部答对的结果 | 校验横幅与下一题、重练、返回课文操作的空间 |

本轮新增状态以这些画板为参照。用户随后明确要求广告沿用已提交的 1.3（build 1），因此横幅位置、高度、请求、重试和插屏频率以该版本为准；不采用画板中的键盘隐藏广告及新增间距，也已移除 QA 横幅预览。其他界面规则见[交互说明](2026-10-11-supplement/interaction-notes.md)，广告核对见[基准记录](../Docs/design/2026-10-11-ad-baseline.json)。

## 后续设计范围

首版已实现词义与单词回想、查看本次答题、本课单词的广告避让；收藏与熟悉程度分开保存，答题不会自动改变熟悉程度或收藏状态。历史错词沿用原记录并持续保留。音频异常的完整视觉稿、历史错词清除规则仍可在后续版本细化。

本轮使用内置 `image_gen.imagegen` 生成，并做了插画与广告间距校对。[完整提示词与修订记录](2026-10-11-supplement/prompts.json) 随图保存。PNG 用于核对视觉与状态，实际字号、触控区和横幅尺寸按交互说明及目标设备布局实现，不从画板像素直接换算。

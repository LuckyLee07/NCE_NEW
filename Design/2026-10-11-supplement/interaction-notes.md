# 设计补充交互说明

> 执行修订（2026-10-11）：用户指定广告沿用已提交的 1.3（build 1）。下文及画板中的横幅新增间距、键盘主动隐藏／恢复广告方案不再执行；实际广告行为以[已提交版本核对记录](../../Docs/design/2026-10-11-ad-baseline.json)为准。

以下是本轮设计提案的行为约定，供后续实现和验收使用。示例课次、题号与成绩不代表用户的实际学习记录。

## 听写输入与反馈

| 状态 | 内容与操作 | 横幅 |
| --- | --- | --- |
| 待输入 | 可重播音频；输入为空时禁用检查答案，保留跳过 | 预留在底部操作区下方 |
| 键盘展开 | 输入框和检查答案同时可见；保留重播与跳过；不足空间时内容滚动 | 暂隐，并释放其布局空间 |
| 答案提交 | 收起键盘；只允许一次判分，显示用户答案与正确拼写 | 在键盘退出的布局变化中恢复 |
| 答题反馈 | 展示释义和例句；由用户点击下一题继续 | 与操作区分开 |

输入示例 `enginer` 是有意拼错；正确答案为 `engineer`。揭晓前不出现正确拼写、释义或可泄露答案的配图。关闭输入自动纠错和拼写建议，保留用户原始输入；可忽略首尾空格与大小写，但不能自动修正漏字。键盘提交键与检查答案行为相同。

跳过单独记录，不冒充答错。结果满足“答对 + 答错 + 跳过 = 本次总题数”；没有跳过时使用画板中的两项统计，有跳过时补上“跳过 N 题”。最后一题的下一步进入结果页，不自动跳转。

## 广告与底部布局

普通课内页由内容区、当前操作区、白色间隔、横幅区域及底部安全区组成。首页、课程、单词本还需在横幅和底部导航之间保留白色间隔。以 20–24 pt 的操作隔离间距作为本轮设计起点，最终结合真实广告尺寸和设备验证。

画板中的灰色区域及“AdMob 横幅占位”文字仅用于设计沟通。实际横幅高度由当前宽度对应的广告尺寸决定；内容适应可用空间，文字和按钮不随之缩小。输入时隐藏横幅，不把它叠在键盘或提交按钮上。恢复横幅时保持输入、题号与已显示的反馈不变。

加载中保持预留区域。本轮建议加载失败时在当前页面保留空白空间，到下次进入页面时再重新决定是否收起，避免按钮在点击过程中移位。页面切换与广告重试策略须在实现时统一；这项约定不表示调整广告请求频率。

## 首次使用与空状态

- 首次进入所选册时，主操作为开始听读，进入该册首个可用课文；不显示虚构的最近学习记录。开始学习后再以真实记录更新首页。
- 课程搜索只针对当前册。清除搜索恢复该册完整目录，保留当前册选择。
- 单词本仅错词筛选为空时，显示暂无错词，隐藏开始复习；查看本册课程进入当前册的课程目录。
- 筛选为空不等于全册掌握。若后续同时使用关键词或熟悉程度筛选，应改为“没有符合条件的单词”，并提供清除筛选操作。
- 最近学习为空时不提供可点击的空列表入口，并隐藏区段右侧的跳转箭头。

## 练习反馈与结果

答错后同时显示正确答案与用户选项，使用文字和图标辅助颜色表达。反馈后由用户手动进入下一题；不倒计时、不自动推进。

有错词时主操作是重练本次错词，次操作为返回课文。全部答对时主操作改为返回课文，次操作为再练一次。成绩仅代表本次练习，不自动修改熟悉程度，也不自动收藏单词。

重练创建新的练习记录，范围取本次答错的单词；原记录保留。查看本次答题应按题序展示用户作答、正确答案和跳过状态，该页面另行补图。本次错词与单词本中的历史错词采用不同范围，历史错词如何移除另行细化。

## 页面切换与记录建议

| 操作 | 建议行为 |
| --- | --- |
| 同课切换听读、单词、练习 | 保留阅读句子、单词位置、题序与未提交输入；不隐式提交 |
| 离开听读或播放其他发音 | 暂停先前音频，避免两个音源重叠；返回后等待用户继续播放 |
| 切换册数 | 各册分别保留最近课次；进入没有记录的册时采用首次使用状态 |
| 临时离开练习 | 保存本次练习草稿；返回可继续原题，不把离开当作答错 |
| 主动重新开始练习 | 如将覆盖未完成草稿，提示继续原练习或重新开始 |
| 切换界面语言 | 保留课程和作答状态，只更新界面及译文；英语学习内容保持不变 |

## 实现验证边界

这些是静态画板，尚未验证真实键盘、广告 SDK 或设备布局。实现时优先验收小屏加键盘、大字号、长释义和多语言，保证内容可滚动、主要操作可达。使用系统字体、原生键盘和可访问的控件；按钮触控范围至少 44 × 44 pt，答对答错不只靠颜色区分。

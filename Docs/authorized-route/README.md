# Authorized Content Route

本目录记录“已取得正式内容授权”前提下的长期开发路线。

适用前提：项目可以合法使用“新概念英语”相关课文、翻译、音频、封面、词表、品牌名称和宣传素材，并且授权范围覆盖 iOS App、离线内置、广告或 IAP 变现、App Store 截图/文案、目标地区和后续版本更新。

如果授权文件没有明确覆盖上述范围，本路线只能作为技术准备文档，不能作为可发布计划。

## 总目标

把当前“离线资料包 + 基础练习 App”升级成稳定、合规、可持续变现的新概念英语学习工具。

核心优势继续保留：

- 离线学习。
- 四册完整内容。
- 课文有声同步。
- 单词学习、听写和测试。
- 本地学习进度与错题记录。

## 基本原则

- 版权授权优先于所有产品投入。
- 先上架稳定，再做学习闭环，再做商业化增长。
- 先本地闭环，后账号服务。
- 不把核心课文学习锁死在付费墙后。
- 广告不能干扰学习过程，只能出现在自然断点。
- 所有数据库变更必须有迁移方案，不能丢用户学习记录。

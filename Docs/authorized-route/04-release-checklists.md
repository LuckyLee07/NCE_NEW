# Release Checklists

## 1. App Store Connect Checklist

- [ ] App 名称和副标题符合授权范围。
- [ ] App 描述不夸大授权范围。
- [ ] 关键词只使用已授权品牌词。
- [ ] 隐私政策 URL 可访问。
- [ ] 支持 URL 可访问。
- [ ] App 隐私问答已更新。
- [ ] 如果请求追踪，隐私问答包含追踪用途。
- [ ] 截图包含真实 App 界面。
- [ ] 截图中展示的教材名、封面、课文内容都在授权范围内。
- [ ] iPhone 6.5/6.7 英寸截图已上传。
- [ ] 13 英寸 iPad 截图已上传。
- [ ] 审核备注准备授权摘要。

## 2. Build Checklist

- [ ] 当前分支明确。
- [ ] build number 已增加。
- [ ] marketing version 正确。
- [ ] Release 配置无测试广告设备。
- [ ] `Info.plist` 中隐私权限描述准确。
- [ ] 如果不请求 ATT，则无无用 `NSUserTrackingUsageDescription`。
- [ ] 如果请求 ATT，则弹窗文案和隐私政策一致。
- [ ] 第三方 SDK 版本已记录。
- [ ] SKAdNetwork 列表已按当前广告 SDK 要求更新。
- [ ] Archive 成功。

## 3. Core Regression Checklist

### 启动与导航

- [ ] 首次启动复制数据库成功。
- [ ] 二次启动不覆盖用户数据库。
- [ ] 四册入口可进入。
- [ ] 每册课程列表正确。
- [ ] 返回按钮正常。

### 课文播放

- [ ] 第一册第一课第一句可播放。
- [ ] 最后一课最后一句完成后不崩溃。
- [ ] 单句播放完成自动下一句。
- [ ] 后台播放可用。
- [ ] 音频中断后可恢复或安全停止。
- [ ] 无音频资源时有降级提示。

### 单词学习

- [ ] 单词显示英文。
- [ ] 单词显示中文。
- [ ] 单词发音可播放。
- [ ] 单词图片缺失时不崩溃。
- [ ] 陌生/熟悉/模糊状态可更新。

### 练习

- [ ] 听写练习可完成。
- [ ] 英汉练习可完成。
- [ ] 汉英练习可完成。
- [ ] 答错后写入错题。
- [ ] 测验结果页显示正确。

### 单词本

- [ ] 未学单词列表可打开。
- [ ] 陌生单词列表可打开。
- [ ] 熟悉单词列表可打开。
- [ ] 模糊单词列表可打开。
- [ ] 做错单词列表可打开。

### 搜索与词典

- [ ] 英文搜索可用。
- [ ] 搜索特殊字符不崩溃。
- [ ] 在线词典可打开。
- [ ] 在线词典加载失败可返回。

### 广告

- [ ] 横幅加载失败不影响布局。
- [ ] 插屏只在自然断点出现。
- [ ] 插屏失败后继续学习。
- [ ] 去广告用户不展示广告。

## 4. Device Checklist

- [ ] iPhone small screen。
- [ ] iPhone large screen。
- [ ] iPad 11 inch。
- [ ] iPad 13 inch。
- [ ] 竖屏。
- [ ] 低网络或无网络。
- [ ] 第一次安装。
- [ ] 从旧版本升级。

## 5. Database Migration Checklist

- [ ] 旧版数据库备份。
- [ ] `schema_version` 存在。
- [ ] 迁移脚本按顺序执行。
- [ ] 迁移失败回滚。
- [ ] 错题记录保留。
- [ ] 单词状态保留。
- [ ] 收藏记录保留。
- [ ] 最近学习记录保留。

## 6. Privacy Checklist

- [ ] 隐私政策描述 AdMob。
- [ ] 隐私政策描述在线词典 WebView 可能访问第三方网站。
- [ ] 如果使用 iCloud，同步数据范围已说明。
- [ ] 如果使用麦克风，说明用途。
- [ ] 如果使用 AI 功能，说明是否上传文本或音频。
- [ ] App Store 隐私问答与实际 SDK 行为一致。

## 7. Release Decision

只有以下全部满足才建议提交审核：

- [ ] 授权范围明确。
- [ ] 隐私项完整。
- [ ] 核心回归通过。
- [ ] 旧版本升级通过。
- [ ] 归档成功。
- [ ] 截图和审核备注准备完成。

# 原生学习界面首版 · 2026-10-11

本版已接入现有 Objective-C iOS 工程，沿用本地四册课文、词汇、音频和多语言资源。

## 已完成

- 学习首页：册数选择、按册续学、最近学习、本课单词与练习入口。
- 课程目录：当前册内搜索课号、英文标题和译文，包含搜索无结果状态。
- 课内页：共用课次标题与「听读 / 单词 / 练习」切换；保留当前阅读句子、单词位置和作答草稿，切换时暂停先前音频。
- 单词：发音、释义、配图、课文例句、熟悉程度、独立收藏和本课单词列表。
- 练习：词义回想、单词回想、听写、英选义、义选英；确认后只判分一次，手动下一题；分别统计正确、错误和跳过。
- 结果：本次错词、错词发音、只练错词、重新练习、查看本次答题及返回课文。原练习记录保留，答题不自动改变熟悉程度或收藏状态。
- 单词本：搜索、待复习 / 熟悉 / 错词 / 收藏筛选及复习入口。小屏和大字号下顶部区域可随列表滚动。
- 广告：按用户要求恢复到已提交的 1.3（build 1）广告行为。沿用原横幅位置、默认高度、请求和失败重试，以及学习完成后的插屏规则；首页保持无横幅。课内容器负责一条横幅，输入键盘不再主动隐藏广告。

## 数据与验证

续学记录按册保存，兼容原有续学键；练习草稿按册、课次和模式区分。保留原数据库与资源键，不迁移课文或音频文件。历史错词仍保留在单词本；清除历史错词的规则尚未增加。

- iPhone 12 Pro / iOS 26.2 主流程 UI 回归：12 项全部通过，覆盖四册听读、四种语言、词汇配图与修正拼写、搜索空状态、各练习模式、错词重练和收藏恢复。
- Foundation 练习状态检查通过：草稿恢复、选项顺序、重复判分保护、跳过计数、错词重练与原记录保留。
- 简繁中文、日语、韩语的生成表、离线查词、课文译文和图片选择检查通过。
- iPhone SE（第 3 代）/ iOS 17.2 与 iPad Pro 13 英寸 / iOS 26.2 专项复核通过：听写与两种选择题完成、草稿和键盘恢复、大字号、课内布局、单词本空状态、重启后收藏恢复。
- 最后的结果页滚动修复已重新构建，并通过三种测试模式的整轮验证；进入结果页时完成标题可见。各轮测试与截图校验信息见[验证记录](2026-10-11-validation.json)。

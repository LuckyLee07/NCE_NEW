# 四语言本地化

状态：简繁体及新增日文、韩文的技术接入、资源校验和增量测试已通过；本轮范围、结果和构建流程见 [日文与韩文说明](japanese-korean.md)。2026-10-06 已在 App Store Connect 的 1.3 待提交草稿保存简繁体、日文、韩文及英语（美国）五套六项商店文案，并扩充关键词，见 [填报记录](app-store-connect-1.3-record.json)。英语（美国）仅为商店文案，不增加英文界面；原英语（加拿大）配置保留不变。未上传新构建或正式截图，未提交审核；最终检查时本地工程 Debug/Release 已同步为 1.3 / build 1。自动转换和机器翻译不能代替母语审校。

## 范围

- 本次支持简体中文、繁体中文、日文和韩文，不加入英文、越南文或泰文界面。
- 首页、学习模式、课名、课文译文、单词释义、听写与测验、搜索、单词本、设置及辅助功能标签均使用本地化读取。
- 设置支持跟随系统、简体中文、繁體中文、日本語和한국어。系统偏好中的首个受支持语言决定版本；只有英文等不受支持偏好时回退简体。台湾、香港、澳门的中文区域代码回退繁体；新加坡中文回退简体，明确的 Hans/Hant 优先于地区。
- 英文课文、英语单词及发音不翻译；学习记录仍使用原始数据库单词键，不使用翻译后的显示名称作为键。
- 繁体文字是独立覆盖层，不改写 `NCE.db` 或课文 ZIP。切换语言会回到设置页，重建页面以清除旧语言缓存，不重建数据库。
- 原创课程只留在内容生产目录，不加入 Xcode 工程或 App。
- App 桌面名称使用 iOS 的 Bundle 本地化；App 内语言设置不能动态修改桌面名称。
- 外部在线词典网页由服务商提供，不保证跟随 App 的文字版本。

## 构建和校验

```sh
python3 -m pip install -r Tools/localization_requirements.txt
python3 Tools/build_chinese_localizations.py
bash Tools/test_chinese_localizations.sh
bash Tools/test_word_resources.sh
bash Tools/test_lesson_packs.sh
```

OpenCC 只用于开发机器生成覆盖层，不加入 App 运行时，也不联网转换用户输入。原图中文检测使用 macOS Vision，首次运行需要允许本地 OCR；缓存带原图 SHA-256。OCR 候选再经视觉判定，不能把英文或数学符号的误识别直接当作需要替换的中文。

编辑术语和界面措辞时修改 `overrides.json`，然后重新生成。不要直接修改生成的 `.strings` 或 `zh-Hant.json`。图片由现有结构化配图配方重新渲染，原 AI 插图和原始 JPEG 保留；128×128、JPEG 质量 0.55、单张不超过 8 KiB。旧繁体变体只在校验属于本流程且哈希未被更改时清理。

构建报告记录 276 个课程条目、4,445 句课文、3,332 条单词记录（3,104 个独立词条）。图片新增繁体变体 1,081 张，约 2.71 MiB；未变更文字的配图直接复用。首页继续保留四册图片入口和原有布局；2026-10-06 最终品牌更新已将 Icon 替换为正中 NCE 字标的四册书脊图，将封面替换为四语言共用的 C 款手绘设计、英文标题和册数编号，见 [设计与校验](../branding/README.md)。导航标题及可访问性标签仍按所选语言显示。四册 ZIP 仍直接离线读取，不拆为下载包。

单词图片本地化以保留原有图片式界面为前提：可可靠制作繁体版本的资源使用独立变体，难以替换的照片或复杂图文保留原图，不仅为去除简体字而改成文字入口。原单词图片不覆盖、不删除；后续重新设计的 Icon 与四册封面另有完整原图备份。繁体单词配图优先读取有效路径下存在的繁体文件；没有映射、路径不合法、文件缺失或路径实际是目录时回退原图。简体模式始终使用原图。当前图片可解码性由构建校验保证，不在每次路径查询时重新解码。

机器证据：`build-report.json`、`preserved-sources.json`、`generated-images.json`。`--verify` 校验覆盖层时也检查原数据库、课文 ZIP、基础图片和音频哈希。覆盖完整不等于语义与地区用语已通过母语审校。

2026-10-06 简繁阶段校验结果（不是日文、韩文最终构建的验收记录）：

- 6 项原生 UI 测试通过：iPhone 12 Pro 四册简繁学习页面、双文字搜索、语言与已标记单词的重启保留、系统语言与英文设备回退；13 英寸 iPad 和 iPhone 13 mini 的双语言布局；小屏双语言听写、两种选择练习及单词本页面。

## 商店素材

六种商店语言的本地上传素材已经生成：简体、繁体、日文、韩文、美国英文及保留的加拿大英文，共 60 张 iPhone/iPad 截图、12 段约 24 秒真实操作预览、12 张视频封面参考。入口为 `StoreAssets/1.3/index.html`，规格和上传顺序见 [素材说明](../../StoreAssets/README.md)。尚未上传，英文商店仍展示真实简体界面，不增加英文 App 菜单。

`store-metadata.json` 提供简体、繁体、日文、韩文及英语（美国）的名称、副标题、关键词、推广文本、描述及更新说明。五套文案已保存于 1.3 草稿；工程里的 `.lproj` 不会自动更新商店信息。保持简体为主要语言，在经营美国商店中文用户及繁体受众的同时，分别测试日本、韩国本地语言受众。美国英文描述明确没有英文界面，不新增 `en.lproj`；加拿大配置不删除、不覆盖。商店元数据语言与 App 界面语言是两件事。

`aso-plan.json` 列出本次 ASO 实施顺序、五张截图表达重点及 14/28 天观察项。简体名称保留用户截图中的现有全称；关键词扩充词汇、跟读、阅读、错题与回想等真实需求，逗号分隔，不使用竞品名或无关热门词。当前字符长度：简体 96、繁体 96、日文 94、韩文 83、美国英文 99；后台保存均未显示校验错误。1.2 旧关键词已记录在填报记录中，但没有搜索量或排名证据，不直接宣称新配置更优。上线前还需保留完整截图基线。没有来源分析时仍可改进商店页，但仅能评价绝对下载变化，不能把全部下载或增长归因于搜索 ASO。Apple 明确把名称、副标题、关键词和用户行为等作为搜索因素，推广文本不影响搜索排名。[搜索说明](https://developer.apple.com/app-store/search/)

本批截图分别展示真实简体、繁体、日文、韩文首页、课文译文、单词、词义练习和单词本；英文商店页共用真实简体截图，预览标题使用英文。两类设备四语言录制通过，6 项素材测试、90 张截图及视频抽帧 OCR、浏览器全部媒体加载和桌面/手机排版检查通过；清单和检查结果在 `StoreAssets/1.3`。为修正实录暴露的问题，本轮统一课文测量和显示字体、增加行高留白，并让 iPad 学习内容从导航栏下方开始，专项搜索/单词/练习测试通过，首页布局不变。QA 关闭广告，不表示验证了生产广告；这些素材检查也不代表母语审校或全 App 功能验收。App 名称与截图不得暗示未经核实的出版社官方身份。

上架前仍需核实各销售地区的内容授权、隐私信息、当前线上版本号和商店配置。本次不自动改售价、地区可用性或上传发布。

## 发布门槛

- 繁体、日文和韩文母语审校：四册课名、常用词和多义词、课文译文、图片短标签及完整商店文案。OpenCC 与机器翻译覆盖率不代表语义准确率。
- 新增路径实机检查：四语言选择与重启保留、当前语言释义搜索、长文字布局、练习显示及旧学习记录保留。
- 回归按改动范围安排：本轮不改生产广告、SDK 或英语音频，不要求重复完整广告验收和全部音频试听。以后改动 SDK、同意配置、播放服务或音频文件时，再增加对应测试。独立 QA 关闭广告，不能当作生产广告验证证据。
- 商店工作：五套文案已保存至 1.3 草稿；六套语言的截图和预览已在本地生成，按素材说明检查后上传。完成母语审校，核对语言展示、授权和隐私声明，再上传构建并送审。工程 Version 已为 1.3；若 1.3 (1) 未上传过，iOS Build 可保留 1，同 Version 的后续上传再递增。原有英语（加拿大）元数据保留未改动，提交前也需检查其完整性。

## 美国下载量的判断

用户提供的 2026-09-05 至 2026-10-04 截图显示全 App 销量 645、变化 +6.1%，美国商店占明显多数；图表没有精确国家数值，不从柱高推算精确比例。这里是首次购买或领取次数，不是收入。Apple 地区统计按客户账单地址对应的商店划分，不证明真实所在地、母语或族群。[指标定义](https://developer.apple.com/help/app-store-connect/reference/reporting/sales-and-trends-metrics-and-dimensions)

美国商店支持简体、繁体本地化信息。[商店语言表](https://developer.apple.com/help/app-store-connect/reference/app-information/app-store-localizations/)

可能原因包括中文标题已有自然搜索曝光、海外中文用户、使用美国商店账户的其他地区用户、网站或其他 App 推荐，以及大陆不可用后其他商店占比上升。这些都是待验证假设，截图不能证明哪一项成立，也不能证明缺少专项 ASO 就没有搜索流量。

在 App Store Connect 的获客分析中选择同一日期范围与美国地区，按来源查看 App Store 搜索、App Store 浏览、App 推荐和网页推荐，再比较展示、产品页访问、首次下载及留存。来源统计不等于完整搜索关键词报告，不据此编造用户搜索词。[获客分析](https://developer.apple.com/help/app-store-connect-analytics/acquisition/acquisition/)
